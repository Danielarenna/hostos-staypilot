# User Stories

## Dashboard

- Como anfitrião, quero visualizar todas as reservas do dia para organizar minha rotina.
- Como anfitrião, quero visualizar meu faturamento mensal para acompanhar meu desempenho.

## Reservas

- Como anfitrião, quero cadastrar uma reserva manualmente para registrar hóspedes de qualquer plataforma.
- Como anfitrião, quero alterar uma reserva facilmente caso o hóspede mude as datas.

## Hóspedes

- Como anfitrião, quero consultar o histórico de um hóspede antes de aceitar uma nova reserva.
- Como anfitrião, quero registrar observações importantes sobre cada hóspede.

## Mensagens

- Como anfitrião, quero enviar mensagens automáticas de boas-vindas para economizar tempo.
- Como anfitrião, quero que o sistema responda perguntas frequentes utilizando IA.

## Limpeza

- Como anfitrião, quero avisar automaticamente a equipe quando houver check-out.
- Como responsável pela limpeza, quero marcar o imóvel como limpo após finalizar o serviço.

## Financeiro

- Como anfitrião, quero visualizar lucro por imóvel.
- Como anfitrião, quero acompanhar todas as despesas relacionadas a cada propriedade.
